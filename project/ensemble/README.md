# Точное воспроизведение ансамбля YouAreBot

Запуск после распаковки:

```bash
python3 run.py
```

Нужен только Python 3.9+; устанавливать библиотеки, скачивать данные или входить в аккаунты не требуется. Результат — `submission.csv` в текущей папке. Существующий файл не перезаписывается; другой путь: `python3 run.py --output result.csv`.

Скрипт заново вычисляет `0.5 × CatBoost + 0.5 × LLM` по настоящим сохранённым вероятностям двух компонентов и проверяет весь CSV по SHA-256. Это **replay сохранённых предсказаний**, не повторное обучение и не новый вызов LLM. Произвольные новые диалоги этот пакет не классифицирует.

Получается побайтово тот же файл на 758 строк, который был отправлен как **#10588** и получил исторический public LogLoss **0.1303426569**:

`4bde02a00f00d009ad69c3aa967c00e468a41c0bcb2b90f65b93416abb3d4639`

Public score локально не вычисляется, новых отправок скрипт не делает. Происхождение компонентов и хеши десяти исходных LLM batches — в `manifest.json`. Сам исходный готовый submission в пакет не включён: он собирается из двух компонентов.

Проверки: `python3 test_replay.py`.
