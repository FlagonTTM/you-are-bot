# Архив исследовательской сессии

Здесь сохранены **неизменённые исходники ранее выполненных экспериментов**, а не новый готовый сервис. Их SHA-256 и размеры перечислены в `source-manifest.json`. Метрики и протоколы находятся в `../evidence/history/`.

## Что относится к какому эксперименту

| Исходники | Назначение |
|---|---|
| `botbench.py`, `experiment.py` | Загрузка диалогов, графовые группы, признаки, классические модели |
| `llm_bridge.py`, `finalize.py`, `campaign.py` | Историческая LLM-ветка, проверки происхождения данных и финальная смесь |
| `research/anchoring_ab.py` | Проверка влияния статистического prior в LLM-запросе |
| `research/template_text.py` | Добавление native text к банку признаков |
| `research/sequence_probe.py` | ByteCNN и GRU по последовательности реплик |
| `research/encoder_assets.py`, `research/encoder_probe.py` | Проверенный локальный pretrained encoder и эксперимент с ним |

**Для воспроизводимого эксперимента рубежного контроля используйте `../run.sh`, а не запускайте архивные скрипты.** Архив сохраняет исходную структуру путей исследовательского workspace. Соответствующие сырые данные, веса и промежуточные результаты сюда не копировались. Поэтому архив сам по себе не является переносимым end-to-end пакетом всех исторических запусков.

## Зависимости и ограничения

- `requirements.original.txt` — исходный список зависимостей классических моделей.
- `requirements.research.lock` — отдельный снимок установленных версий зависимостей исследовательских прототипов, включая транзитивные зависимости. Он получен на macOS / Python 3.13.2; установка в чистой среде другой ОС не проверялась.
- `environment.json` — состав этого снимка и границы воспроизведения.
- Исторический encoder: `intfloat/multilingual-e5-small`, revision `614241f622f53c4eeff9890bdc4f31cfecc418b3`. Веса в Git не включены; автоматическая загрузка не запускается.
- Историческая LLM-ветка использовала внешнюю модель `gpt-6.1-sol` через авторизованный Codex CLI. Аккаунт, секреты и сырые запросы не включены. Новый вызов внешней модели не гарантирует побайтового воспроизведения прежнего ответа.
- Сохранённые исторические JSON-отчёты не переименованы в новые MLflow-запуски. Новый baseline имеет отдельный реальный SQLite/JSON-трекинг.

Результаты отрицательных экспериментов сохранены. Они не использовались как основание для нового соревновательного upload.
